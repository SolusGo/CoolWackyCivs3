# Cool Wacky Civs 3

26 human-only civilizations for Civilization V: Brave New World with standalone Community Patch v151.

Open [CoolWackyCivs3.civ5sln](CoolWackyCivs3.civ5sln) in **ModBuddy** (Civilization V SDK). Set the Civilization V game/user paths in ModBuddy, choose **Default**, then **Build → Build Solution** (F6). This packages the mod and deploys it to your configured `MODS` folder.

- [Project file](Wacky3/CoolWackyCivs3.civ5proj)
- [Build instructions](Wacky3/README.md#build-in-modbuddy)
- [Civilizations, requirements and installation](Wacky3/README.md)

The SDK package appears at `Packages/Cool Wacky Civs 3 (v 1).civ5mod`; intermediate files are in `Build/Cool Wacky Civs 3`. These folders are beside this README. Python is only required to regenerate content or update the project inventory after adding/removing files: run `python tools/build_mod.py` from `Wacky3`, then reload the project.
