# Repository artwork

[Collection README](../../README.md) · [Civilization gallery](../Civilizations.md)

The cover was created for this repository using built-in ImageGen. Each JPEG in `leaders/` is a web preview of the matching civilization's diplomacy scene. The original texture is the `FallbackImage` named in that civilization's `Art/*LeaderScene.xml`.

## Cover prompt

```text
Use case: stylized-concept. Asset type: wide GitHub README cover illustration for the third Cool Wacky Civs mod pack. Paint a single strange but inviting strategy-game world: an old mountain railway crosses a deep ravine beside a golden railway station with a glass conservatory; on the other side a cathedral of amethyst crystal rises under a misty dusk sky and several tiny colorful kites drift above the valley. Visual cues for the Perpetual Timetable, the Hollow Choir, the Glass Orchard and the Kingdom of a Thousand Kites. Rich painterly concept art with plum, lavender, garnet and warm gilded lantern light. Large readable shapes and atmospheric depth. Compose as an ultra-wide landscape banner (ideally 3:1) with the key subjects in the central horizontal third so it can be cropped wide. No title, typography, lettering, interface, frame, logos, or watermark.
```
