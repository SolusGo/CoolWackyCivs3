# Daily Surprise mechanics in CP v151

The following contracts are based on the [CP151 source pin](https://github.com/LoneGazebo/Community-Patch-DLL/tree/44c1e14ff75d80c1dba5c8a71e8289439a53aafb/CvGameCoreDLL_Expansion2). Local copies are verified by the pack's source audit. The SQLite and Lua 5.1 tests exercise the implemented SQL and Lua. Native timing and delivery of the Lua hooks still require a Civ V session.

| Contract | Pinned implementation and consequence |
| --- | --- |
| Coastal cities and classes | `CvLuaCity::lIsCoastal` calls `CvCity::isCoastal`. Use the CP ocean-area minimum, as native coastal effects do. `lGetNumBuilding` includes real and free buildings. |
| Native friendly defense and coastal defense | `CvUnit::GetMaxDefenseStrength` and the non-attacking branch of `GetMaxRangedCombatStrength` consume `DefenseMod`. Melee attack and the ranged attack branch omit it. `BattleStarted` precedes these calculations in `CvUnitCombat`. Scoped defenders are repaired on movement and before battle. `CvPlot::IsFriendlyTerritory` includes eligible Open Borders. Coastal land defense uses native adjacency to water and checks passability. |
| Windrunner | `CvUnit::GetMaxAttackStrength` reads the explicit attack modifier from `pToPlot->getTerrainType()`. The neutral defense column and underlying terrain preserve the attacking-only Plains/Grassland condition, including hills and features. |
| Mirrorbound | `CvUnitCombat::ResolveCombat` publishes `CombatResult` after abort checks and `CombatEnded` after native resolution. The 15 arguments carry roles, damage/max HP and location. Verify lethal target damage and actual death together. The stored attack promotion uses `AttackMod`, which is read only in the attack branches of the native strength functions. `BattleTypeTypes` starts with melee at 0. `CvPlayer::setTurnActive(false)` publishes `PlayerDoneTurn` to expire unused counters after their last owner turn. Interception and collateral attribution remain incomplete. |
| Courier | `CvPlayer::setTurnActive(false)` invokes `DoUnitReset`; `CvUnit::restoreFullMoves` copies `maxMoves` into the real movement store. The next `PlayerDoTurn` reconciles that store using `CvLuaUnit::lGetMoves`, `lSetMoves` and `lMaxMoves` and the current promotion delta. Changing the listed maximum alone would not restore movement. Losing eligibility removes remaining bonus movement and reentry cannot restore it in the same turn. |
| Economy and fallback | `CvPlayer::doTurnPostDiplomacy` settles cities and research before `PlayerDoTurn`. Recovery there affects the following payout. Building hooks, capture, improvement changes and city UI dirtiness cover more immediate state, subject to the engine publishing each event. |
| State | Records are namespaced within existing ScriptData. Reconciliation sets each city controller to exactly 0/1 and clears free copies without construction rewards. Starting terrain/Hills use the stable city-center geography. A third-party script that changes that geography or bypasses all ordinary game events is outside the target. |
