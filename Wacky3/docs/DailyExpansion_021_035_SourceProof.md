# Daily Surprise mechanics in CP v151

The following contracts are based on the [CP151 source pin](https://github.com/LoneGazebo/Community-Patch-DLL/tree/44c1e14ff75d80c1dba5c8a71e8289439a53aafb/CvGameCoreDLL_Expansion2). Local copies are verified by the pack's source audit. The SQLite and Lua 5.1 tests exercise the implemented SQL and Lua. Native timing and delivery of the Lua hooks still require a Civ V session.

| Contract | Pinned implementation and consequence |
| --- | --- |
| Coastal cities and classes | `CvLuaCity::lIsCoastal` calls `CvCity::isCoastal`. Use the CP ocean-area minimum, as native coastal effects do. `lGetNumBuilding` includes real and free buildings. |
| Native friendly defense and coastal defense | `CvUnit::GetMaxDefenseStrength` and the non-attacking branch of `GetMaxRangedCombatStrength` consume `DefenseMod`. Melee attack and the ranged attack branch omit it. `BattleStarted` precedes these calculations in `CvUnitCombat`. Scoped defenders are repaired on movement and before battle. `CvPlot::IsFriendlyTerritory` includes eligible Open Borders. Coastal land defense uses native adjacency to water and checks passability. |
| Windrunner | `CvUnit::GetMaxAttackStrength` reads the explicit attack modifier from `pToPlot->getTerrainType()`. The neutral defense column and underlying terrain preserve the attacking-only Plains/Grassland condition, including hills and features. |
| Mirrorbound | `CvUnitCombat::ResolveCombat` publishes `CombatResult` after abort checks and `CombatEnded` after native resolution. The 15 arguments carry roles, damage/max HP and location. Verify lethal target damage and actual death together. The stored attack promotion uses `AttackMod`, which is read only in the attack branches of the native strength functions. `BattleTypeTypes` starts with melee at 0. `CvPlayer::setTurnActive(false)` publishes `PlayerDoneTurn` to expire unused counters after their last owner turn. Interception and collateral attribution remain incomplete. |
| Courier | `CvPlayer::setTurnActive(false)` invokes `DoUnitReset`; `CvUnit::restoreFullMoves` copies `maxMoves` into the real movement store. The next `PlayerDoTurn` reconciles that store using `CvLuaUnit::lGetMoves`, `lSetMoves` and `lMaxMoves` and the current promotion delta. Changing the listed maximum alone would not restore movement. Losing eligibility removes remaining bonus movement and reentry cannot restore it in the same turn. |
| Economy and fallback | `CvPlayer::doTurnPostDiplomacy` settles cities and research before `PlayerDoTurn`. Recovery there affects the following payout. Building hooks, capture, improvement changes and city UI dirtiness cover more immediate state, subject to the engine publishing each event. |
| State | Records are namespaced within existing ScriptData. Reconciliation sets each city controller to exactly 0/1 and clears free copies without construction rewards. Starting terrain/Hills use the stable city-center geography. A third-party script that changes that geography or bypasses all ordinary game events is outside the target. |

| Stage B contract | Pinned implementation and consequence |
| --- | --- |
| Era selection | CvTeam::SetCurrentEra updates the era before TeamSetEra. The panel and its gameplay handlers run in one InGameUIAddin context. The click handler re-reads the human active player and current-era record, saves the choice, then reconciles cities and promotions. While a vote is pending no resolution operates. Starting in a later era opens a vote for the starting era. |
| Marsh | CvPromotionClasses reads Feature Defense and DoubleMove independently. CvUnit applies both through its feature counters; its defense branches read the defender feature. CvUnitMovement::GetMovementCostMultiplierFromPromotions at blob 3bf4ef1b9954a4d6b5481856326ad90d434af053 halves movement for the destination feature unless a higher precedence Hill or Mountain modifier already determines cost. The Fen Stalker's +15 and the civilization's +10 are separate feature defense promotions. |
| Temporal debt | CvCity::doProduction combines actual order-adjusted production, feature production and overflow, then clears the stores and may pop/finish the order before PlayerDoTurn. CvPlayer::doResearch adds actual research plus previously scaled overflow and can irrevocably finish a tech. CP's Lua progress writes and the post-economy PlayerDoTurn event expose no verified interception of the exact per-turn yield before completion, overflow, and project rewards. Modifiers change rates and cannot prove an exact capped debit. No advances, debt, temporary debt modifiers or advance UI are enabled. |
| Tile ownership and work | CvLuaPlot::lGetCityPurchaseID returns the native owning city ID; each radius-three plot is credited to that city alone. CvLuaCity::lIsWorkingPlot checks citizen assignment. The automatically worked city center is excluded from worked-only bonuses. Radius checks use native wrapped hex geometry and deduplicate plot IDs. |
| Glass Orchard | CvTeam::setAtWar updates the state before GameplayWarStateChanged. The Lua UI event repairs peace rewards and normal turn/city events recover them. Native Garden placement tests FreshWater independently from other requirements. Only the replacement's FreshWater flag is cleared. Worked pillaged Desert counts for the Gold and building Science thresholds, but not the Food ability. |

| Stage C contract | Pinned implementation and consequence |
| --- | --- |
| Reveal provenance | CvPlot::setRevealed emits TileRevealed only on the unrevealed-to-revealed transition. It supplies team, source team, and the CvUnit pointer's owner/ID. Own-unit sight supplies that pointer through CvPlot::changeAdjacentSight. Shared maps identify the source team, and trade routes and scripted reveals can supply neither a unit nor a source team. City-driven sight also supplies no unit, so exact city-only attribution is blocked. The ledger records unique personal claims, carry-over and paid rewards per era. Initial and reload census is all-source and is used exclusively by Atlas House. |
| Research rewards | CvLuaTeamTech::lChangeResearchProgress and the native CvTeamTechs implementation complete the selected tech and preserve excess in research overflow, as audited for the Directorate. An unselected technology uses ChangeOverflowResearch. A save-backed receipt is written before award callbacks can advance the era. Quick, Standard, Epic and Marathon grant 10/7, 15/10, 23/15 and 45/30 Science/Culture. |
| Muisca | CvLuaPlot::lGetResourceType, lIsResourceConnectedByImprovement and lIsLake use resource, improvement and native lake classifications. Currency mines can qualify for both effects. Mine Gold does not depend on the resource being Gold or Silver. |
| Garrison | CvPlot::getBestGarrison uses CanGarrison and compares land/naval contributions. CvCity::GetGarrisonedUnit can return an override. The duchy checks the city-center stack directly for an owned, living, non-embarked land combat unit. This prevents a naval or scripted garrison from qualifying. UnitSetXY fires after garrison movement and UnitPrekill fires before removal. |
| Cover I | The Expansion2 Civ5UnitPromotions XML and standalone load use PROMOTION_COVER_1. The Chair Marshal grants that existing row and inherits its active ranged defense and upgrade setting. No percent override is introduced. |
| Cloud Sentinel | CvUnit::GetRangeCombatDamage may use GetMaxRangedCombatStrength for a defending archer. HillsDefense also applies in that non-attacking branch. To preserve the design's melee-defense-only rule, the lineage applies a scoped HillsDefense promotion in the verified melee BattleStarted callback and clears it at BattleFinished. Native preview before BattleStarted does not see this scoped modifier. |
| WLTKD transitions | CvCity::ChangeWeLoveTheKingDayCounter writes the new counter before CityBeginsWLTKD or CityExtendsWLTKD. DoTestResourceDemanded decrements and emits CityEndsWLTKD after reaching zero. Retirement and renewal are reconciled synchronously in these hooks. |
| WLTKD payout boundaries | CvCity::doTurn performs production before DoTestResourceDemanded. CvPlayer::doTurnPostDiplomacy collects treasury and research after the city turns. At natural expiry, production can settle with the old positive counter on the turn that science and gold see zero. At natural start, the opposite boundary applies. The Lua controllers respond to the actual native counter when each yield is read. Native logs and stored totals still need acceptance. |
